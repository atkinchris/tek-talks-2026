The attack

One function to patch.

The patch

Disable module signing

The manufacturer's signing check is custom code, not upstream Linux. One function. We overwrite it with a return instruction in the kernel binary on disk.

→

The result

Key extracted

The patched kernel accepts our unsigned module. It runs at EL1, reaches the secure register, and reads out the encryption key.

They signed the modules but forgot to sign the kernel itself.
