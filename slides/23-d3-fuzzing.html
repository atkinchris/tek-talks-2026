"How do we find a vulnerability? We could read the code line by line. Or we could throw thousands of malformed inputs at it and see what crashes."

Walk through the pipeline left to right: "We start with a valid splash logo. AFL - American Fuzzy Lop - takes that input and mutates it thousands of times. Flipped bytes, truncated headers, oversized fields."

Point to the grid: "Most of the time the parser handles it fine. But one mutation crashes it."

"A crash means the software did something unexpected. And unexpected behaviour is exploitable."
